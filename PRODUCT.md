# FC Besa 05

## Platform
Web. Einfache Vereinswebsite für Fans, Interessierte und Spieler in Leopoldshöhe.

## Stack
Statisches HTML, CSS und JavaScript, ohne externe Laufzeitabhängigkeiten. Docker Compose für eigenes Hosting. Als technische Entscheidung nach der Aufforderung zur direkten Umsetzung gewählt.

## Inhalt
Recherchiertes Vereinslogo, Vereinsinformationen, Spielplan und Anfahrt. Keine erfundenen Ergebnisse, Ansprechpartner oder Trainingszeiten. Daten sind ein datierter redaktioneller Stand, kein Livefeed.
